## Суть и Живое Предназначение

> *«Ты просто печатаешь поток своей мысли — на русском, английском или в их живой смеси.  
> Эта лёгкая и бережная утилита невидимо выравнивает всё сама, чтобы твоя мысль никогда не рвалась о переключение клавиш.  
> **Ноль телеметрии. Ноль слежки. Твой поток информации — это твоя информация и твоя суверенная база.**»*

Когда человек думает и пишет быстро, мысль обгоняет руки. Нажатие не той клавиши раскладки (`ghbdtn` вместо `привет`), зависший `Caps Lock` (`пРИВЕТ`), лишний символ в смешанной речи (`&` вместо `?` после английского слова в русской фразе) каждый день рвут концентрацию.

**`Avalon.Shifter`** создан как тихий, невесомый **Выравниватель Потока Информации (`432.0 Гц`)**:
- **Живой поток без границ между языками:** свободно смешивайте русские слова, английские термины, код (`git commit`, `app.py`, URL, пути файлов) и короткие союзы — утилита понимает контекст строки за `< 1 мс` и не портит программный код (`Developer Guard`).
- **Стильный живой индикатор раскладки в трее:** вместо безликого значка панель задач показывает чёткий контрастный бейдж текущей раскладки ОС — **`RU`** (матовый обсидиан с тёплым золотом Кинцуги) и **`EN`** (чистый алебастр с обсидиановым контуром), а при активной Базе Потока загорается аккуратная золотая капля `432 Гц`.
- **Чистый интерфейс без лишнего шума + «Под капотом» по одному клику:** на главном экране — только ясность и покой (`RU / EN`), а все живые параметры движка, векторы `R4`, статус Надзирателя `OTP` и официальные ссылки на `GitHub` и `Hugging Face` Автора бережно собраны в спокойном меню **«Автор • OMNISAVALON»** и вкладке **«Под капотом • Прозрачность»**.

## Личная База Потока (для обучения вашего ИИ — строго Opt-In)

По вашему **добровольному решению** (строго **ВЫКЛЮЧЕНА по умолчанию** — `0` байт записи, пока вы сами не переведёте тумблер) в `Avalon.Shifter` встроена **Суверенная База Потока (`SovereignFlowCorpus`)**:

1. **Зачем это нужно:** всё, что вы печатаете за день в разных программах и мыслях, после выравнивания раскладки и орфографии клавиш может собираться в вашу **собственную локальную базу знаний** — основу для персонального ИИ-ассистента, говорящего вашим языком и знающего ваш стиль.
2. **Многослойный щит приватности (Никаких паролей и секретов):**
   - автоматическое отключение записи при фокусе в полях паролей и менеджерах паролей (`KeePass`, `Bitwarden`, `1Password`, системные окна ввода пароля);
   - жёсткий фильтр токенов (`ghp_`, `github_pat_`, `hf_`, `sk-`, `Bearer`, `JWT`), банковских карт, OTP-кодов, URL с учётными данными и высокоэнтропийных паролей;
   - только обезличенная общая метка среды (`editor`, `browser`, `chat`, `notes`, `office`, `app`) — без сохранения заголовков ваших вкладок и путей файлов.
3. **Защита от раздувания (Суверенная Оригами-Свёртка `.qholo`):**
   - 64-битная гармоническая дедупликация **`AGLS-432-Phi`** автоматически пропускает повторяющиеся фразы;
   - активный слой ограничен `<= 2 МБ`, после чего автоматически свёртывается суверенным словарно-оригами кодеком (`AVALON_FLOW_PACK_V1` / `.qholo`) с общим потолком `<= 16 МБ` без единой сторонней базы или архиватора.
4. **Один клик — экспорт для ВСЕХ ИИ-моделей (локальных и облачных):**

| Файл экспорта | Назначение | С какими ИИ совместим |
| :--- | :--- | :--- |
| `avalon_flow_chat_sft.jsonl` | Диалоговые пары `user` / `assistant` (`JSONL`) | `Gemini`, `Claude`, `Vertex AI`, `Hugging Face SFTTrainer`, `Unsloth`, `Axolotl`, `Ollama`, `LM Studio` |
| `avalon_flow_pretrain.jsonl` | Чистый текстовый корпус потока (`text` / `lang` / `context`) | `llama.cpp`, `mlx-lm`, `Llama`, `Qwen`, `Gemma`, `OLMo` |
| `avalon_flow_knowledge.md` | Хронологический конспект знаний с Хроно-Паспортом | `NotebookLM`, `Gemini Gems`, `Claude Projects`, `Obsidian`, локальный RAG |
| `avalon_flow_sovereign.qholo` | Суверенный голографический кристалл под печатью `AGLS-432-Phi` | `AVALON.OS`, `AVALON-NEXUS`, `Avalon.Veritas` |

## Суверенные технологии OMNISAVALON в основе утилиты

`Avalon.Shifter` не зависит от тяжёлых корпоративных фреймворков, облачных SDK, скрытых библиотек баз данных и сетевых трекеров:

| Слой | Суверенная технология | Назначение |
| :--- | :--- | :--- |
| **Нативная оболочка** | `AvalonShifter.exe` (`Rust #![no_std]`) | Мгновенный запуск (`~18 КБ`) без лишних дочерних окон и без мигания рабочего стола |
| **Базис и крипто-печать** | **САБ-432** + **`AGLS-432-Phi`** + **`.qholo`** | Дедупликация потока, целостность кристаллов и обратимая свёртка без сторонних архиваторов |
| **Лингвистическое ядро** | **`.avl` (`INTENT`)** + **`R4(ru, en, code, ctx)`** + `Developer Guard` | Контекстное выравнивание фраз, ретроактивное исправление предлогов и союзов, `&` → `?` |
| **Память и орбиты** | **`EmpathicMemoryCrystal`** + **`ПЛАЗМА-432`** + **`OTP Supervisor`** | Локальная адаптация из ваших ручных правок (`Double Shift`) и чистые самоисцеляющиеся светлые орбиты |
| **Тороидальная шкала** | Золотая Спираль Всеединства **`ЗСВ-8192`** | Преемственность со всей экосистемой `AVALON.OS` и Ксено-Архивом `НГСС-432` |
